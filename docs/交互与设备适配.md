# 站内浏览与手机连接设计

候票台把“发现活动 → 核对条件 → 进入官方页面 → 记录结果”作为一个任务流程。界面借鉴 [Linear 的视图和导航](https://linear.app/docs/display-options)保持任务可扫描，借鉴 [Apple 的颜色原则](https://developer.apple.com/design/human-interface-guidelines/color)用中性底色、明确焦点和少量蓝色标出可操作控件。官网区域采用浏览器式标签页：每个平台保留自己的页面历史和登录会话，切换标签不重新搜索。官网内容始终由平台提供，候票台不修改排队、选座或支付页面。

[DICE](https://dice.fm/) 的活动发现和 [SeatGeek 的座位视图](https://support.seatgeek.com/hc/en-us/articles/360007200934-Where-does-SeatGeek-get-its-venue-maps)启发了“先找到具体活动、再核对可接受票档”的顺序；候票台目前没有授权的实时座位图，因此不绘制虚构座位或库存。[Queue-it](https://queue-it.com/developers/custom-waiting-room-themes/) 区分等待前、排队中、放行后和错误状态；候票台据此把排队会话视为需要保护的官方页面，不自动刷新，也不生成未经平台确认的队列进度。

## 登录和内置网页

官网从发现页或任务页进入时，都在候票台主窗口的对应平台标签中打开。从任务进入会显示固定人数、总预算、票档与返回入口。平台在登录过程中通过 HTTPS 跳转或请求不带表单提交的前台新页时，内置网页尝试在当前标签继续，并显示实际域名。只有回到所选平台的官方域名，才允许“读取活动信息”。非 HTTPS 跳转、后台弹窗和需要提交表单的新窗口会被阻止。若站点要求浏览器特定能力、拒绝 Electron、依赖独立弹窗的 `window.opener` 或原生 App，用户可显式将当前 HTTPS 页面交给系统浏览器或官方 App；系统浏览器不会继承候票台的登录 Cookie 或排队会话。当前改动验证了大麦未登录账号页可在内置网页打开，**没有登录用户账号或验证登录后的订单页**。

## USB 设备支持

| 设备 | 当前能力 | 必要条件与边界 |
| --- | --- | --- |
| vivo X300 Ultra | ADB 授权和大麦 App 原生启动已实测；普通大麦项目 HTTPS 链接实测进入 vivo 浏览器 | 需要 USB 数据连接、解锁、USB 调试授权及 Google Platform Tools。启动大麦 App 后仍需在 App 内定位具体活动。 |
| OPPO、华为、小米、三星及其他 Android | 共用 ADB 状态诊断和官方 HTTPS 链接发送逻辑；尚未逐品牌实测 | 系统可能用浏览器打开普通链接；每个 App 的原生入口应单独核实。软件不绕过手机授权。 |
| iPhone | 提供 Apple 官方连接说明；任务和官网仍可在 Windows 使用 | iPhone 不支持 ADB。Windows 可用 Apple Devices 和手机上的“信任此电脑”检查连接，但本项目不能通过 USB 远程启动 iOS 购票 App。 |

本机通过 Windows 包管理器安装了 Google Platform Tools 37.0.1，`adb.exe` 位于 `%LOCALAPPDATA%\ticket-window-tools\platform-tools\`。用户也可从 [Google 官方 Platform Tools 页面](https://developer.android.com/tools/releases/platform-tools)下载安装；候票台会搜索 PATH、此目录和常见 Android SDK 目录。安装包不捆绑 `adb`。若 Windows 已显示手机但 `adb` 不存在，状态会分别指出驱动识别与工具缺失；`unauthorized`、`offline`、多台手机也有不同提示。手机入口不读取屏幕、不模拟点击、不自动购买。

在 vivo X300 Ultra 上，`adb devices` 显示已授权，大麦包 `cn.damai` 可被启动；发送大麦官方项目 HTTPS 链接后，前台为 `com.vivo.browser`。这符合 [Android App Links 的路由规则](https://developer.android.com/training/app-links/verify-applinks)：网址是否进入原生 App 取决于域名关联验证和设备设置，不能仅凭官方域名推断。本版因此让每条销售机会覆盖任务级渠道设置。需要原生 App 的大麦机会只启动大麦 App；没有实测入口的其他平台提示手动打开。此能力不保证直达具体场次，也不代表其他 Android 机型已经验收。
